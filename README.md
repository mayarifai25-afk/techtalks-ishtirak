# Ishtirak (اشتراك) - Subscription & Utility Billing Web App

A modern full-stack web application built for managing subscriptions and utility meter billings, featuring automated OCR processing for electricity meters.

##  Tech Stack
* **Framework:** Next.js (App Router, TypeScript)
* **Styling:** Tailwind CSS
* **Database :** PostgreSQL 


##  Prerequisites & Version Requirements
Before running the project, make sure you have the following installed on your machine:
* **Node.js:** Version `20.x` or higher (Recommended: `v26.x`)

##  Getting Started for Team Members

1. **Clone the repository:**
   `git clone https://github.com/mayarifai25-afk/techtalks-ishtirak.git`
   `cd techtalks-ishtirak`

2. **Install dependencies:**
   `npm install`

3. **Run the development server:**
   `npm run dev`
